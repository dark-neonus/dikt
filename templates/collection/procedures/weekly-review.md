# Weekly Review

1. Select the requested week, defaulting to the current local ISO week.
2. Generate `dikt report week`, adding `--date YYYY-MM-DD` for another week.
   Review daily summaries and logged outcomes; do not infer unlogged work.
3. Inspect active/blocked tasks, overdue items and `dikt list --revisit-due`.
   Also evaluate relevant decisions' free-text revisit conditions.
4. Suggest a short list of priorities, blockers to resolve, and decisions needing
   renewed evidence. Separate observations from recommendations; do not auto-accept choices.
5. Preserve worthwhile new knowledge or decisions through dikt, only if supported
   and not already recorded. Update task progress only when confirmed by evidence.
6. Write a concise weekly Summary outside the report's generation markers,
   preserving any existing human text. Validate modified items and cite saved IDs.
