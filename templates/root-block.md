## DIKT project memory

This project keeps durable decisions, ideas, knowledge and tasks in `{{ROOT}}/`, managed by the `dikt` CLI (`{{DIKT}}`).

- Before relevant research, implementation or decision analysis, search existing records: `{{DIKT}} list --query "topic"`, then `{{DIKT}} get <ID> --full` for relevant IDs.
- Write items only through `{{DIKT}}`; never hand-edit files in `{{ROOT}}/tasks`, `ideas`, `knowledge` or `decisions`. Load the `dikt` skill for command details.
- Preserve only verified, reusable knowledge and meaningful decisions; log real progress on tasks; never mark a decision accepted without the user's approval.
- Full rules: [{{ROOT}}/AGENTS.md]({{ROOT}}/AGENTS.md). Placement: [{{ROOT}}/STRUCTURE.md]({{ROOT}}/STRUCTURE.md).
